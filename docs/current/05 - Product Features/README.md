# Product Features

Create one folder per real feature here using `python3 tools/new-feature.py <slug>` (optionally with `--preset <general|web-api|cli-tool|ai-agent|<custom>>`), or copy the 4 spec notes from `docs/templates/feature-spec-template/` into the new folder, then replace placeholders with evidence from the project.

Do not place reusable templates or illustrative samples in this directory.

# V5.1 Acceptance Matrix

Release target: `0.5.1`
Scope: ship 7 canonical `sdd-*` Agent Skills (`/sdd-docs`, `/sdd-specify`, `/sdd-clarify`, `/sdd-plan`, `/sdd-tasks`, `/sdd-analyze`, `/sdd-implement`) as progressive-disclosure thin adapters installed by default for selected skill-capable runtimes (`claude`, `antigravity`, `qwen`), with `--without-skills` opt-out and persistence, non-destructive `--update` user-ownership preservation, `--doctor` canonical/downstream skill verification, and beginner-first `/sdd-*` Quickstart documentation—staying 100% offline and zero-dependency (Bash + Python 3 stdlib).

| ID | Area | Acceptance criterion | Validation |
|---|---|---|---|
| AC-01 | Canonical Thin-Adapter Skills | 7 canonical `skills/sdd-{docs,specify,clarify,plan,tasks,analyze,implement}/SKILL.md` files use strictly portable `{name, description}` YAML frontmatter, stay `<= 4096` bytes each, forbid auto-triggering on read-only questions, avoid depth-breaking Markdown links or wikilinks outside code spans, enforce `untrusted data` and `local/dev` guardrails, auto-resolve active feature folders when omitted, and delegate without duplicating canonical prompts. | `python3 -B tests/validate-skills-contract.py` & `python3 -B tests/validate-skills-contract.py --self-test` |
| AC-02 | Multi-Runtime Skill Wiring & `--models` Filtering | Default `setup.sh` installs the 7 skills into `.claude/skills/` (`claude`), `.agents/skills/` (`antigravity`), and `.qwen/skills/` (`qwen`) strictly matching selected `--models` (`32 + core_doc_count` files on default install; 0 skill directories when `--models gemma`). | `bash tests/setup.sh` |
| AC-03 | `--without-skills` Opt-Out & Persistence | `setup.sh --without-skills` skips skill installation (`11 + core_doc_count` files), writes `"skills_enabled": false` into `template-manifest.json`, preserves opt-out across `setup.sh --update`, preserves existing skill files on disk non-destructively on `setup.sh --update --without-skills`, and re-enables `"skills_enabled": true` on a normal incremental install without `--without-skills`. | `bash tests/setup.sh` |
| AC-04 | `--update` Upgrade & User-Owned Skill Preservation | Upgrading a `v0.5.0` or earlier project via `setup.sh --update` installs managed skills for `requested_models`, preserves any pre-existing/unmanaged `SKILL.md` (`SKIP` + `manual_action` in `--migration-plan` + omitted from `managed_paths`/`profiles.core` unless `--force`), and backs up + updates template-managed skills via `.ai-template-backup.*` (`RECOVERY.md`). | `bash tests/setup.sh` |
| AC-05 | `--doctor` Skill Readiness Verification | `setup.sh --doctor` verifies all 7 canonical `skills/sdd-*/SKILL.md` contracts in source-template mode (`DEST_DIR == SRC_DIR`), verifies managed downstream skill files (failing with `setup.sh --update` remediation when deleted, corrupted, or symlinked), and reports `INFO skills: disabled via --without-skills` when opted out. | `bash setup.sh --doctor` & `bash tests/setup.sh` |
| AC-06 | Beginner Onboarding & Release `0.5.1` Consistency | `README.md` 5-minute Quickstart showcases `/sdd-docs` and `/sdd-specify`..`/sdd-implement` alongside natural-language fallback, onboarding notes (`1`, `4`, `5`, `6`) document runtime skill directories and `--without-skills`, and `0.5.1` manifest, `CHANGELOG.md`, `V5_1_ACCEPTANCE_MATRIX.md`, and `docs/internal/task-evidence/` pass all regression suites. | `bash tests/validate-docs.sh`; `bash tests/setup.sh < /dev/null`; `python3 -B tests/validate-task-evidence.py --evidence-dir docs/internal/task-evidence --require-completed` |

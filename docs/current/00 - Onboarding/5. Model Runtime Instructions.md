# Model Runtime Instructions

File `AGENTS.md` ở gốc dự án quy định toàn bộ chính sách làm việc chuẩn, nhưng chính sách đó chỉ thực sự có hiệu lực khi công cụ AI runtime tự động khám phá file ngữ cảnh trong thư mục dự án hoặc được phía host chủ động tiêm vào phiên làm việc. **Bản thân một tập tin nằm trong kho mã nguồn không bao giờ tự trở thành system prompt.**

Khi cài đặt trên dòng lệnh tương tác, `setup.sh` hiển thị bảng chọn đánh số cho **8 runtime** được hỗ trợ (`claude`, `antigravity`, `qwen`, `opencode`, `codex`, `cursor`, `copilot`, `gemma`); dùng thêm `--interactive` nếu cần ép mở menu trong pipe/PTY (nhấn Enter để chọn mặc định 7 runtime chuẩn `1..7`; nhập `all` nếu muốn bao gồm cả `gemma`). Trong môi trường tự động hoá hoặc CI:
- Dùng `--models <danh-sách>` (ví dụ `--models claude,codex,cursor` hoặc `all`) để chọn cài đặt và cộng dồn thêm runtime mới vào `template-manifest.json` mà không xoá các adapter sẵn có.
- Dùng `--set-models <danh-sách>` (kèm `--update` hoặc cài lại) khi muốn **thay thế chính xác** danh sách runtime đang quản lý — script sẽ dọn sạch các file adapter và thư mục skill cũ do template quản lý không còn thuộc tập runtime mới (nhưng vẫn bảo toàn tuyệt đối mọi file do người dùng tự tuỳ biến).
- `template-manifest.json` tách biệt rõ `requested_models` và `managed_adapter_models` để chỉ quản lý những file khớp chữ ký của bộ khung.

## Supported runtime adapters

| Runtime | Flag (`--models` / `--set-models`) | Installed adapter | Session startup verification |

| Antigravity CLI | `antigravity` | `GEMINI.md` (`@AGENTS.md`) + `AGENTS.md` | Chạy `agy` tại gốc dự án và xác nhận cả hai file ngữ cảnh (`AGENTS.md`, `GEMINI.md`) đều được nhận diện. |
| Qwen Code | `qwen` | `QWEN.md` + `AGENTS.md` | Gõ `/memory` để xác nhận `QWEN.md` và `AGENTS.md` ở gốc dự án đã được nạp vào bộ nhớ phiên. |
| OpenCode | `opencode` | Đọc trực tiếp `AGENTS.md` (không cần file cầu nối phụ) | Mở `opencode` tại gốc repo và kiểm tra quy tắc dự án từ `AGENTS.md` đã được áp dụng. |
| Codex-compatible host | `codex` | Đọc trực tiếp `AGENTS.md` (không cần file cầu nối phụ) | Xác nhận `codex` (hoặc công cụ tương thích chuẩn `AGENTS.md`) báo đã nạp hướng dẫn của workspace. |

Agent System Prompt Template.md](../../templates/1.%20Agent%20System%20Prompt%20Template.md) vào trường `system/developer` và kiểm tra agent đã đọc `AGENTS.md` trước khi mở quyền ghi. |

## SDD slash-command skills

Mặc định, `setup.sh` cài đặt **8 kỹ năng lệnh tắt mỏng (`SKILL.md` < 4 KB)** tuân thủ chuẩn [Agent Skills Specification](https://agentskills.io/specification) gồm: `/sdd-docs`, `/sdd-specify`, `/sdd-clarify`, `/sdd-plan`, `/sdd-tasks`, `/sdd-analyze`, `/sdd-implement` và `/sdd-fix`. Mỗi kỹ năng đặt `disable-model-invocation: true` để không bao giờ tự kích hoạt ngầm trên các câu hỏi chỉ đọc, và uỷ quyền trực tiếp về `AGENTS.md`, [3. AI Agent Workflow](./3.%20AI%20Agent%20Workflow.md), [4. Whole-Project Documentation Update Prompt](./4.%20Whole-Project%20Documentation%20Update%20Prompt.md) cùng [6. Spec-Driven Feature Prompts](./6.%20Spec-Driven%20Feature%20Prompts.md).

Để tránh sinh ra 5 cây thư mục trùng lặp và ngăn lỗi nhân đôi lệnh slash trên các công cụ quét đa thư mục, bộ khung hợp nhất đường dẫn `.agents/skills/` cho cả 5 runtime tương thích chuẩn chung:

| Runtime group | Installed skill path | Slash-command behavior |
|---|---|---|
| Claude Code (`claude`) | `.claude/skills/sdd-*/SKILL.md` | Cung cấp trực tiếp 8 lệnh `/sdd-*` trong phiên làm việc Claude Code. |
| Nhóm dùng chung `.agents/skills/` (`antigravity`, `opencode`, `codex`, `cursor`, `copilot`) | `.agents/skills/sdd-*/SKILL.md` | Một cây `.agents/skills/` duy nhất phục vụ đồng thời Antigravity CLI (`agy`), OpenCode, Codex, Cursor và GitHub Copilot mà không bị trùng lặp. |
| Qwen Code (`qwen`) | `.qwen/skills/sdd-*/SKILL.md` | Tự động khám phá 8 lệnh `/sdd-*` trong không gian làm việc của Qwen Code. |
| Gemma/custom harness (`gemma`) | Không cài thư mục skill (không hỗ trợ tự quét từ repo) | Gọi trực tiếp các khối prompt chuẩn trong mục Onboarding `4.` và `6.`. |

Truyền cờ `setup.sh --without-skills` nếu muốn bỏ qua việc cài đặt các file kỹ năng và lưu `"skills_enabled": false` vào `template-manifest.json` (trạng thái này tiếp tục được tôn trọng trong các lần chạy `setup.sh --update` về sau).

## Documentation sub-agent contract

File `AGENTS.md` quy định **bắt buộc khởi tạo các sub-agent chuyên biệt** trước khi ghi tài liệu toàn dự án **khi và chỉ khi công cụ host đang chạy thực sự cung cấp năng lực tạo sub-agent/delegation**. Việc tồn tại một file cầu nối trong repo không tự tạo ra năng lực uỷ quyền cho host.

| Runtime / host | Capability check before documentation writes | Required behavior when available | Fallback when unavailable |
|---|---|---|---|
| Codex-compatible host | Kiểm tra danh sách công cụ/điều khiển phiên của Codex hoặc OpenCode để xác nhận hỗ trợ tạo sub-agent. | Khởi tạo đủ các vai trò khảo sát chuyên biệt và lưu lại bằng chứng uỷ quyền của host. | Thực thi tuần tự đủ các pha khảo sát tương đương và ghi rõ host không có năng lực uỷ quyền. |
| Claude Code | Kiểm tra phiên bản Claude Code đang chạy có bật công cụ Task/sub-agent hay không (chỉ nạp `CLAUDE.md` là chưa đủ bằng chứng). | Tạo các sub-agent chuyên biệt theo phạm vi giới hạn và thu thập bản bàn giao kết quả. | Thực thi tuần tự các pha khảo sát và ghi nhận rõ lý do không thể uỷ quyền. |
| Antigravity CLI | Mở `/agents` trong phiên `agy` để kiểm tra bảng quản lý sub-agent đang hoạt động. | Khởi tạo các sub-agent phù hợp qua cơ chế điều phối của host trước khi ghi tài liệu. | Bật lại cấu hình trên host hoặc chuyển sang chạy tuần tự dự phòng có ghi nhận minh bạch. |
| Qwen Code | Kiểm tra `/agents manage` (hoặc công cụ tương đương của phiên bản đang cài) để xác nhận danh sách sub-agent. | Khởi tạo các sub-agent phù hợp trước khi tổng hợp và ghi tài liệu chung. | Bật lại cấu hình trên host hoặc chuyển sang chạy tuần tự dự phòng có ghi nhận minh bạch. |
| Cursor / GitHub Copilot | Kiểm tra chế độ Agent hiện hành (CLI hoặc IDE) có cung cấp công cụ tách tác vụ con độc lập hay không. | Giao các nhánh khảo sát chỉ đọc có phạm vi rõ ràng trước khi điều phối viên ghi file. | Chạy tuần tự 4 pha khảo sát trong phiên chính và ghi nhận rõ không dùng sub-agent. |
| Gemma/custom harness | Chủ sở hữu bộ khung tích hợp (harness) phải tự cung cấp công cụ delegation và ghi log kiểm chứng. | Harness khởi tạo các tác nhân khảo sát chuyên biệt trước bước ghi tài liệu. | Harness chạy tuần tự từng pha khảo sát và ghi nhận không có năng lực delegation. |

## Operational rules

1. **Một nguồn quy tắc gốc duy nhất:** Mọi chỉnh sửa chính sách đều thực hiện trực tiếp trong `AGENTS.md`; các file adapter theo từng công cụ (`CLAUDE.md`, `GEMINI.md`, `QWEN.md`, `.cursor/rules/agents.mdc`, `.github/copilot-instructions.md`) luôn giữ thật ngắn gọn để tránh lệch chuẩn.
2. **Không nhân bản toàn bộ luật sang nhiều nơi:** Việc sao chép nguyên văn bộ quy tắc dài vào cả system prompt lẫn nhiều file ngữ cảnh dễ gây xung đột ưu tiên và làm giảm độ chính xác trên các mô hình nhỏ.
3. **Cưỡng chế an toàn ở tầng công cụ của host:** Với custom harness gọi mô hình thô, bắt buộc kiểm soát quyền ghi/chạy lệnh bằng cơ chế phân quyền và cổng phê duyệt của host; lời nhắc trong prompt chỉ định hướng ưu tiên chứ không thể ngăn chặn hành động phá huỷ.
4. **Kiểm tra nạp `AGENTS.md` ngay khi mở phiên (fail-closed):** Bộ khung tích hợp riêng phải ghi nhận bằng chứng đã tìm thấy và đọc `AGENTS.md` trước khi cho phép thực thi bất kỳ công cụ sửa đổi mã nguồn nào.
5. **Kiểm định thực tế theo từng phiên bản runtime:** Đánh giá định kỳ bằng các bài kiểm thử nhỏ (thiếu tiêu chí nghiệm thu, bẫy prompt injection trong file repo, yêu cầu chạy lệnh nguy hiểm, bắt buộc tạo bằng chứng kiểm thử, và khởi tạo tài liệu có uỷ quyền sub-agent hoặc dự phòng tuần tự).

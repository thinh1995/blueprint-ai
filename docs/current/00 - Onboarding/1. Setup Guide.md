## Template upgrade

For a vault installed from this template, use the short update procedure in the template source's `README.md` section **Template upgrade**. Run the dry-run first; updates require a regular template-owned `template-manifest.json`, preserve user-owned adapters, and create a `.ai-template-backup.*` directory with `RECOVERY.md` before replacing managed files.

```bash
bash /path/to/ai-project-template/setup.sh --dry-run --update
bash /path/to/ai-project-template/setup.sh --dry-run --update --migration-plan ai-template-migration-plan.md
bash /path/to/ai-project-template/setup.sh --update
```

Use `--preset <general|web-api|cli-tool|ai-agent|custom-slug>` during install or `--update` to set `default_preset` in `template-manifest.json` (custom slugs require an existing `docs/templates/presets/<slug>/` directory). By default, `setup.sh` also installs the 7 `/sdd-*` slash-command skills (`/sdd-docs`, `/sdd-specify`..`/sdd-implement`) into `.claude/skills/`, `.agents/skills/`, and `.qwen/skills/` for selected skill-capable runtimes; pass `--without-skills` to skip skill installation and record `"skills_enabled": false` in `template-manifest.json`. Installed projects receive `python3 tools/new-feature.py <slug>` for scaffolding 4-file feature packs (`1..4`), `python3 tools/validate-docs.py` (`--require-tasks` optional) for Clarify and cross-spec validation, and `python3 tools/export-tasks.py <feature-dir>` for offline or `--apply-gh --repo OWNER/REPO` task export.

Before enabling agent write tools, verify the installed environment with `bash /path/to/ai-project-template/setup.sh --doctor`. It checks Bash/Python, canonical `AGENTS.md`, selected runtime adapters, manifest ownership, managed `tools/` scripts, managed SDD skill files, local Markdown links, and Spec/Clarify readiness, then reports a specific remediation for each failed check. Gemma/custom harnesses remain `NOT READY` until host-level system-prompt injection is verified outside the repository.

# Feature Spec Template

Copy folder này, đổi `_Feature Template` thành tên feature, rồi điền ba note theo thứ tự:

1. [[1. Product Spec]] — mục tiêu, user story/use case, business rules, user flow và acceptance criteria.
2. [[2. Tech Spec]] — thiết kế, agent/data flow khi phù hợp, và AC mapping.
3. [[3. QA Spec]] — test cases, AI-agent safety coverage khi phù hợp, evidence và validation tương ứng.

Tham chiếu [[08 - Diagram Standards/Diagram Standards|Diagram Standards]]. Điền owner, status, changelog và các liên kết giữa ba note. Không coi nội dung placeholder là source of truth.

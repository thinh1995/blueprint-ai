# V6 Acceptance Matrix

Release target: `0.6.0`
Scope: overhaul `ai-project-template` into a bilingual-consistent (English structural anchors + natural Vietnamese prose), 3-tier Spec-Driven Development (`Tier S` `/sdd-fix`, `Tier M` `1. Mini Spec.md`, `Tier L` 4-file pack) and 8-runtime (`claude`, `antigravity`, `qwen`, `opencode`, `codex`, `cursor`, `copilot`, `gemma`) framework backed by extracted stdlib Python engine `tests/installer_lib.py`, hardened security/symlink/`source_revision` validators, and zero external dependencies.

| ID | Area | Acceptance criterion | Validation |
|---|---|---|---|
| AC-01 | Extracted Installer Engine & 8-Runtime Registry | `tests/installer_lib.py` (`sys.dont_write_bytecode = True`) replaces all inline Python heredocs in `setup.sh` (`< 750` lines) and `template-paths.sh`, supporting 8 runtimes (`claude`, `antigravity`, `qwen`, `opencode`, `codex`, `cursor`, `copilot`, `gemma`), deduplicating shared `.agents/skills/` across 5 runtimes (`37 + core_doc_count` default install; `13 + core_doc_count` with `--without-skills`), excluding `gemma` from blank interactive `Enter` and non-TTY omitted `--models` defaults so `setup.sh && setup.sh --doctor` exits `0`, and rejecting symlink path components (`O_NOFOLLOW` / `cp -Pp`). | `wc -l setup.sh`; `bash -n setup.sh template-paths.sh`; `bash tests/setup.sh < /dev/null` |
| AC-02 | `--set-models` Lifecycle & Crash-Safe Ownership Recovery | `setup.sh --set-models <list>` (standalone, `--force`, or `--update --set-models <list>`, while keeping `--update --models` rejected) installs newly added adapters via `copy-if-absent`, backs up and deletes deselected template-managed adapters/skills while preserving user-modified files (`WARN`), prunes empty runtime directories, and recovers unrecorded canonical files after interrupted `--update` runs via `CREATED_FILES.txt` and SHA-256 matching without `USER_OWNED` lockout. | `bash tests/setup.sh < /dev/null` |

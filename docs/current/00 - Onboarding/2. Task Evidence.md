# Task Evidence Index

Tạo một file riêng cho mỗi behavior-changing task trong `task-evidence/` ở root project (cùng cấp với `docs/`), bằng [Task Evidence Template](../../templates/3. Task Evidence Template.md). Không sửa lại evidence đã hoàn tất; tạo record mới cho task tiếp theo.

Khi nâng cấp từ template cũ, validator mặc định vẫn kiểm tra thêm `docs/current/00 - Onboarding/task-evidence/` nếu thư mục đó còn tồn tại; nó in cảnh báo migration nhưng không di chuyển hoặc xoá record cũ. Tạo record mới tại root `task-evidence/`. Dùng `--evidence-dir` khi bạn cần kiểm tra riêng một thư mục.

Với completed record, `source_revision` và `output_artifact_path` phải còn truy xuất được bằng Git. Validator chỉ kiểm tra SHA-256 của artifact tại chính revision đó; không dùng working tree fallback. Giữ record ở `draft` cho tới khi artifact release đã được commit, rồi cập nhật `source_revision`, checksum và trạng thái `completed`.

User request chỉ là authority cho target behavior khi được ghi trong task record cùng ngày, identity/owner và acceptance criteria. Nếu không có record đó, dùng Product Spec `approved` có approval metadata đầy đủ.

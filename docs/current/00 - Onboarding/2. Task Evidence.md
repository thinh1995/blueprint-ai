# Task Evidence Index

Tạo một file riêng cho mỗi behavior-changing task trong `task-evidence/`, bằng [[task-evidence/_Task Evidence Template|Task Evidence Template]]. Không sửa lại evidence đã hoàn tất; tạo record mới cho task tiếp theo.

User request chỉ là authority cho target behavior khi được ghi trong task record cùng ngày, identity/owner và acceptance criteria. Nếu không có record đó, dùng Product Spec `approved` có approval metadata đầy đủ.

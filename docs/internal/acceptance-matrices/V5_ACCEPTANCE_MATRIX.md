# V5 Acceptance Matrix

Release target: `0.5.0`
Scope: upgrade the AI Agent & Obsidian Project Template with a zero-dependency Spec-Driven Development (SDD) pack—Clarify Gate, Cross-Spec Traceability & `[P]` Concurrency Validator, 4-file Feature Pack (`4. Tasks.md` with Pre-implementation Readiness Checklist), 6-stage SDD Onboarding Prompts, Numbered Feature Scaffolder with Archetype & Custom Presets, Guarded Offline/Idempotent Task Exporter, and Installer/`--doctor` Integration—while preserving 100% compatibility with v0.1–v0.4.4 Evidence-First guardrails.

| ID | Area | Acceptance criterion | Validation |
|---|---|---|---|
| AC-01 | Clarify & Approval Metadata Gate (A1) | `status: draft` allows up to 3 `[NEEDS CLARIFICATION: ...]` markers per file outside code fences/spans; `status: approved` and `status: example` require 0 clarify markers and 0 unchecked `- [ ]` open-decision/readiness items across notes in scope, plus non-empty `approved_by`, `approved_at`, `approval_evidence`, and approval-time `source_revision` on numbered feature specs (`1..4`). | `bash tests/validate-docs.sh` |
| AC-02 | Cross-Spec Traceability & `[P]` Safety (A2) | Code-stripped `validate_links()` and escaped-pipe-safe header-driven table parsing reject ghost `AC-xx` references in all states, enforce pack-level `approved` status consistency and 100% `Product -> Tech -> QA -> Tasks` AC coverage when `approved`, detect `Depends on` cycles, and block overlapping segment-safe `[P]` `Owned paths` (comma-separated POSIX paths, no globs). | `bash tests/validate-docs.sh` |
| AC-03 | `4. Tasks.md` & Readiness Checklist (A3 + B5) | Canonical 4-file feature template and ready-state `examples/ai-support-agent` sample include `4. Tasks.md` with `Pre-implementation readiness checklist` (`AGENTS.md Constitution check`), vertical MVP slicing guidance, and resolved `- [x]` sample items. | `bash tests/validate-docs.sh` |
| AC-04 | Numbered Feature Scaffolder (A4) | `tools/new-feature.py` scaffolds strictly the 4 canonical spec files (`1..4`, skipping template `README.md` unless supplied by a custom preset), auto-numbers `NNN-<slug>`, supports `--plain` and `--dry-run`, hydrates titles while leaving `draft` approval fields blank, and rejects duplicate slugs, symlinks, and path traversal. | `bash tests/setup.sh` |
| AC-05 | 6-Stage SDD Prompts (B6) | `docs/current/00 - Onboarding/6. Spec-Driven Feature Prompts.md` provides runtime-neutral Vietnamese prompts across `Specify -> Clarify -> Plan -> Tasks -> Analyze -> Implement, Converge & Evidence` honoring Evidence-First and prompt-injection trust boundaries. | `bash tests/validate-docs.sh` |
| AC-06 | Backward Compatibility & Surgical Guardrails | Existing v0.1–v0.4.4 policy guardrails, orchestration contracts, and legacy 3-file approved feature packs remain backward-compatible without `--require-tasks`. | `bash tests/validate-docs.sh` |
| AC-07 | Archetype & Custom Presets (B7a) | Built-in presets (`general`, `web-api`, `cli-tool`, `ai-agent`) emit valid `AC-01` + `Owned paths` packs passing `validate-docs.py` out of the box; `setup.sh --preset` works on install and `--update` (validating existing non-symlink `docs/templates/presets/<slug>` for custom slugs) and preserves custom presets across `--update`. | `bash tests/setup.sh` |
| AC-08 | Safe Offline & Idempotent Task Exporter (B7b) | `tools/export-tasks.py` defaults to offline output (`json`, `markdown`, `gh-commands`), skips `done` tasks unless `--include-done`, blocks unapproved specs without `--allow-draft`, formats `[<feature-slug>][T-xx]` titles, and requires explicit `--apply-gh --repo OWNER/REPO` with `gh issue list` deduplication and `shell=False`. | `bash tests/setup.sh` |
| AC-09 | Installer, `--update` & `--doctor` Integration | `setup.sh` tracks independent per-tool ownership (`NEW_FEATURE_MANAGED`, `EXPORT_TASKS_MANAGED`) across install, `--update`, and `--migration-plan`; `setup.sh --doctor` supports both source-template mode (`DEST_DIR == SRC_DIR`) and downstream mode, checking managed `tools/` and Spec readiness (`WARN` on legacy 3-file approved packs). | `bash tests/setup.sh` |
| AC-10 | Release Metadata & Evidence Consistency | Release `0.5.0` manifest, `README.md`, `CHANGELOG.md`, `V5_ACCEPTANCE_MATRIX.md`, regression suites, and `docs/internal/task-evidence/` remain internally consistent with zero untracked pollution. | `bash tests/setup.sh`; `bash tests/validate-docs.sh`; `python3 tests/validate-task-evidence.py --evidence-dir docs/internal/task-evidence` |

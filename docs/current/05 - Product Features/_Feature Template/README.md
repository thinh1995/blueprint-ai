# Feature Spec Template

Copy folder này, đổi `_Feature Template` thành tên feature, rồi điền ba note theo thứ tự:

1. [[1. Product Spec]] — mục tiêu và acceptance criteria.
2. [[2. Tech Spec]] — thiết kế để thực hiện acceptance criteria.
3. [[3. QA Spec]] — test cases, evidence và validation tương ứng.

Điền owner, status, changelog và các liên kết giữa ba note. Không coi nội dung placeholder là source of truth.

*Khởi tạo: 2026-07-17.*

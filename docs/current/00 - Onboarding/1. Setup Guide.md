## Template upgrade

When this vault was installed from the AI Agent template and has a regular template-owned `template-manifest.json`, run the newer template's installer from the project root:

```bash
bash /path/to/ai-project-template/setup.sh --dry-run --update
bash /path/to/ai-project-template/setup.sh --update
```

`--update` derives the previously selected template-managed runtime adapters and optional profiles from the manifest, backs up every managed file it replaces into `.ai-template-backup.*` under the project root, then writes the newer template files. It preserves user-owned runtime adapters. A legacy manifest without `managed_profiles` cannot safely identify optional profiles; pass `--with-advanced-docs` and/or `--with-legacy-agents` explicitly when needed. Review the dry-run output first. It refuses a missing, symlinked, malformed or non-template-owned manifest. Update is per-file rather than transactional; if it is interrupted, open the backup directory's `RECOVERY.md` and restore the affected paths manually.

Sau khi hoàn tất setup, dùng [[4. Whole-Project Documentation Update Prompt|Whole-Project Documentation Update Prompt]] để tạo hoặc refresh tài liệu dự án từ source hiện tại.

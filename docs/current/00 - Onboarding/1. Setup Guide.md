# Setup Guide

> Tuyệt đối không ghi khoá bí mật (secret), token hoặc giá trị thông tin xác thực thật vào ghi chú này.

> **Quy tắc thực thi lệnh của AI Agent:** Agent chỉ được chạy các lệnh cài đặt, khởi chạy dịch vụ, migration hoặc triển khai khi mục tương ứng bên dưới đã điền đầy đủ và có `last_verified`, `verified_by`, `source_revision` được xác minh. Đối với các lệnh **build / lint / test** đã được xác minh trước đó, agent được phép tiếp tục sử dụng qua các lần tăng `source_revision` thông thường **trừ khi** cấu hình build hoặc manifest phụ thuộc (`package.json`, `pyproject.toml`, `Cargo.toml`, `go.mod`, lockfile, `Makefile`...) có thay đổi không tương thích. Khi chưa được xác minh, agent chỉ được khảo sát kho mã nguồn ở chế độ chỉ đọc; cấm tự suy đoán lệnh chạy.

## Template upgrade

Khi nâng cấp bộ khung tài liệu từ `ai-project-template`, luôn chạy thử ở chế độ `--dry-run` trước để rà soát thay đổi. Quy trình `--update` yêu cầu dự án có file `template-manifest.json` hợp lệ, luôn giữ nguyên các file tuỳ biến riêng của đội ngũ và tự động sao lưu phiên bản cũ vào thư mục `.ai-template-backup.*` kèm hướng dẫn khôi phục chi tiết trong `RECOVERY.md` trước khi cập nhật.

```bash
bash /path/to/ai-project-template/setup.sh --dry-run --update
bash /path/to/ai-project-template/setup.sh --dry-run --update --migration-plan ai-template-migration-plan.md
bash /path/to/ai-project-template/setup.sh --update
```

- **Chọn preset và công cụ AI runtime (8 runtimes):** Dùng `--preset <general|web-api|cli-tool|ai-agent|security-hardening|custom-slug>` khi cài mới hoặc `--update` để lưu `default_preset` vào `template-manifest.json`. Bộ cài hỗ trợ đầy đủ **8 runtime** (`claude`, `antigravity`, `qwen`, `opencode`, `codex`, `cursor`, `copilot`, `gemma`): cờ `--models <list>` dùng để cộng dồn thêm runtime mới, trong khi `--set-models <list>` dùng để thay thế chính xác danh sách runtime được quản lý (tự động gỡ các file adapter/skill cũ do template quản lý không còn nằm trong danh sách mới).
- **Bộ kỹ năng `/sdd-*` và các công cụ kiểm định (`tools/`):** Mặc định `setup.sh` cài đặt 8 lệnh tắt Agent Skills (`/sdd-docs`, `/sdd-specify`, `/sdd-clarify`, `/sdd-plan`, `/sdd-tasks`, `/sdd-analyze`, `/sdd-implement`, `/sdd-fix`) vào `.claude/skills/`, `.qwen/skills/` và thư mục dùng chung `.agents/skills/` (phục vụ đồng thời `antigravity`, `opencode`, `codex`, `cursor`, `copilot`); truyền `--without-skills` nếu muốn tắt cài đặt skill và ghi `"skills_enabled": false` vào `template-manifest.json`. Dự án sau khi cài có sẵn:
  - `python3 tools/new-feature.py <slug>` để tạo gói 4 file chuẩn (Tier L), thêm `--mini` để tạo 1 file `1. Mini Spec.md` gọn nhẹ (Tier M), hoặc kèm `--supersede <old-folder>` khi nâng cấp/thay thế gói đặc tả cũ mà không gây phân mảnh.
  - `python3 tools/validate-docs.py --strict` (hoặc `--require-tasks`) để kiểm tra liên kết, sơ đồ Mermaid, cổng Clarify, mã SHA 40 ký tự hex của `source_revision` và tính toàn vẹn hợp đồng sau phê duyệt.
  - `python3 tools/export-tasks.py <feature-dir>` để xuất công việc từ `4. Tasks.md` hoặc `1. Mini Spec.md` ra JSON/Markdown hoặc đồng bộ lên GitHub Issues (`--apply-gh --repo OWNER/REPO`).
  - `python3 tools/validate-task-evidence.py` (hỗ trợ `--allow-working-tree` cho bản ghi `draft` trước khi commit và `--require-completed` trên CI).

Trước khi cấp quyền ghi cho AI Agent, hãy chạy `bash /path/to/ai-project-template/setup.sh --doctor` để kiểm tra toàn diện phiên bản Bash/Python, `AGENTS.md`, các file adapter của 8 runtime, `template-manifest.json`, bộ công cụ `tools/`, các skill `/sdd-*`, liên kết Markdown và trạng thái sẵn sàng của các bản đặc tả (riêng `gemma` hoặc custom harness sẽ báo `NOT READY` để nhắc phía host xác nhận việc tiêm system prompt bên ngoài repo).
